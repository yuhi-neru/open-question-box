# JPYC: 実装前の確認事項

2026-10-14確認。MVPの決済は無効で、秘密鍵や利用者資金を保存せず、送金要求・手数料・API料金の徴収を実施しない。

## 確認できたこと

JPYCには対応ウォレットに関する公式案内がある。実装時は発行元の最新案内で、対象となるJPYC、チェーン、コントラクト、decimals、ブリッジや旧トークンとの違いを特定する必要がある。旧資料のアドレスを最新仕様として利用しない。

- [JPYC EX 対応ウォレット](https://faq.jpyc.co.jp/s/article/user-wallet-supported)
- [金融庁: 電子決済手段等取引業](https://www.fsa.go.jp/common/shinsei/dendai/dentori.html)
- [金融庁: 電子決済手段・暗号資産サービス仲介業](https://www.fsa.go.jp/common/shinsei/denanchuukai/index.html)
- [金融庁: FinTechサポートデスク](https://www.fsa.go.jp/news/27/sonota/20151214-2.html)

金融庁資料には仲介・管理等に関する登録制度が記載され、秘密鍵保有等により主体的に移転できる場合の管理該当性も説明されている。**非カストディアル、投げ銭手数料0%というだけで、サービスが登録不要とは判断しない。**この文書は個別サービスに対する法的判断ではない。

## 本番有効化前

事業形態、受取人、送金指図、運営関与、API有効化料金や残高、返金、地域制限、消費者保護、AML/KYC、税務、利用規約がどの制度に該当するかを専門家・必要なら当局に確認する。公式JPYC仕様の確認日と出典を残す。チェーンID・コントラクトを公式出典と一致させ、整数で金額を扱う。送信者がウォレット上で宛先・金額・ガス代・ネットワークを確認して署名する。運営による代理署名、預かり残高、秘密鍵保管を作らない。

## 段階

1. 決済なしの匿名質問MVP（現在）。
2. 本番と切り離したテストネットでウォレット接続と直接送金を検証。拒否・誤チェーン・小数・重複・reorg・失敗をテストする。
3. 法的前提が確認された場合にだけ、明示的に有効化されたチェーンのJPYC直接送金を提供。プラットフォーム手数料は0%、ガス代は別表示。保有していない人の匿名投稿は維持する。
4. API有効化10 JPYCと従量課金は投げ銭と独立した将来機能。利用量、料金、同意、取消、支払確認を別途設計し、未検証の送金で権限を与えない。セルフホスト版の基本APIを公式課金に依存させない。
